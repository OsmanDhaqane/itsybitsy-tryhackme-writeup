# ItsyBitsy - TryHackMe Write-up

This repository contains my write-up for the TryHackMe room **ItsyBitsy**.

The room focused on investigating a suspected C2 communication alert using Kibana and HTTP connection logs. The investigation included reviewing March 2022 events, identifying the suspected user IP, checking the Windows binary used for the download, finding the C2 URL, and extracting the secret code from the accessed Pastebin file.

## Room Focus

- Kibana Discover
- HTTP connection log analysis
- C2 communication investigation
- Suspicious source IP identification
- `bitsadmin.exe` abuse
- Pastebin-based C2 activity
- Basic SOC alert investigation
